# Habit Tracker with Streak Heatmap

A simple habit tracker that lets you log daily habits and visualize your consistency with a GitHub-style contribution heatmap. Built as a Chingu Solo Project (Developer Track, Tier 1).

🔗 **Live demo:** https://jht127.github.io/habit-tracker-heatmap/
📦 **Repo:** [https://github.com/JHT127/habit-tracker-heatmap]

## Features

- ➕ Add and delete custom habits
- ✅ Mark habits as done for the current day
- 🔥 Automatic current streak calculation (consecutive days with at least one habit completed)
- 🏆 Longest streak tracking
- 📅 GitHub-style heatmap showing the last 90 days of activity, with hover tooltips
- 🌙 Dark mode toggle
- 💾 All data persists locally via `localStorage` — no backend or database required

## Tech Stack

- HTML5
- CSS3 (CSS Grid, custom properties, responsive layout)
- Vanilla JavaScript (no frameworks or libraries)
- Browser `localStorage` for data persistence

## How It Works

- Habits and daily completions are stored as JSON in `localStorage`.
- The heatmap is generated by looping over the last 90 days, counting how many habits were completed on each day, and mapping that count to a color intensity level (similar to GitHub's contribution graph).
- The current streak is calculated by walking backward day by day from today until a day with zero completions is found.
- The longest streak is calculated by scanning all recorded completion dates and finding the longest run of consecutive days.

## Running Locally

No build step or dependencies needed. Just open `index.html` in any modern browser, or serve the folder with any static file server.
